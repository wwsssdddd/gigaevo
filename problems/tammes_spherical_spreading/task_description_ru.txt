СФЕРИЧЕСКОЕ РАСПРЕДЕЛЕНИЕ ТАММЕСА (24 ТОЧКИ)

ЦЕЛЬ
Разместить ровно 24 индексированные точки p_1, ..., p_24 на единичной сфере
    S^2 = {p из R^3 : ||p||_2 = 1}

так, чтобы наименьшее евклидово расстояние по всем парам различных индексов
было как можно больше.

КОНСТРУКЦИЯ
Реализуйте функцию `entrypoint()`, возвращающую вещественный числовой массив
формы (24, 3). Строка i содержит декартовы координаты точки
p_i = (x_i, y_i, z_i).

ОГРАНИЧЕНИЯ ДОПУСТИМОСТИ
 Результат должен преобразовываться в вещественный массив float64 формы
(24, 3).
 Каждая координата должна быть конечной. Значения NaN, положительная и
отрицательная бесконечность недопустимы.
 Каждая строка должна задавать точку единичной сферы. Валидатор допускает
радиальную ошибку не более 1e-7 и перед вычислением оценки радиально
проецирует принятые точки на точную единичную сферу.

ЦЕЛЕВАЯ ФУНКЦИЯ
Для нормированных точек определяется
    fitness = min по всем 1 <= i < j <= 24 величины ||p_i - p_j||_2.

Значение fitness необходимо максимизировать. Его универсальный диапазон:
от 0 до 2. Для каждой принятой конструкции валидатор возвращает fitness
вместе с is_valid = 1.

ПОВЕДЕНИЕ ВАЛИДАТОРА
  Функция `validate` вызывает ValueError только в следующих случаях: результат
имеет неправильную форму, не преобразуется в вещественные числа, содержит
NaN или бесконечность либо содержит строку за пределами допуска единичной
сферы.
  Совпадающие точки принимаются. Если две строки одинаковы, расстояние между
ними равно нулю, поэтому fitness также равен 0.
  Почти совпадающие точки и скопления точек тоже принимаются
  Перед оцениванием каждая принятая строка нормируется, поэтому
масштабирование не может увеличить fitness.

ЧИСЛЕННОЕ СОГЛАШЕНИЕ
Используются евклидовы расстояния по хордам в R^3
Если центральный угол пары равен t, то длина хорды равна 2 * sin(t / 2)
Валидатор вычисляет расстояния по разностям координат
